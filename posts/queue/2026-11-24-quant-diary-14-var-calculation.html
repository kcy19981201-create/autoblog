--- title: 퀀트 공부 일기 #14 - VaR 계산 방법 labels: 퀀트 공부 일기, 금융공학, VaR ---

2026년 11월 24일.

지금까지는 상품 하나의 가격과 민감도를 구했다. 리스크관리에서는 질문이 바뀐다. "이 포지션을 하루 들고 있으면 나쁜 날 얼마까지 잃을 수 있나." 이걸 숫자 하나로 답하는 게 VaR(Value at Risk, 위험가치)다. 정의는 "신뢰수준 99%에서 1일 동안 이보다 크게 잃을 확률이 1%인 손실 금액"이다. 계산 방법은 크게 세 가지, 분산-공분산법, 역사적 시뮬레이션, 몬테카를로다. 그릭스는 #6, 몬테카를로는 #7에서 다뤘고, 전체 지도는 #0 프롤로그에 있다.

직관: 손익 분포의 왼쪽 1% 지점

내일 포지션의 손익을 확률분포로 그려 본다. 대부분은 0 근처에 몰리고, 가끔 크게 벌거나 잃는다. 이 분포에서 왼쪽 끝부터 1% 를 잘라낸 경계선이 99% VaR 이다. 수식으로 쓰면 손실 L 에 대해 P(L > VaR) = 1% 가 되는 값, 즉 손실 분포의 99% 분위수다.

두 가지를 꼭 같이 말해야 한다. 기간(1일, 10일)과 신뢰수준(95%, 99%)이다. "VaR 500만원"만으로는 의미가 없다. 그리고 VaR 은 "1% 의 나쁜 날에 얼마나 잃는지"는 말해 주지 않는다. 경계선 너머의 평균 손실을 보는 게 기대손실(ES, Expected Shortfall)이고, 바젤 시장위험 기준(FRTB)은 97.5% ES 를 쓴다.

왜 지금 이 숫자가 중요한지는 최근 코스피만 봐도 알 수 있다. 아시아경제 보도로 2026년 11월 17일 코스피는 132.02포인트(2.59%) 내린 4,968.48에 마감해 약 9개월 만에 5,000선 아래에서 끝났다. 바로 며칠 전인 11월 11일에는 2.60% 오른 5,375.36(머니투데이방송)이었다. 하루 2~3% 가 위아래로 오가는 장이다.

세 가지 계산 방법

1. 분산-공분산법 (모수적 방법)

수익률이 정규분포를 따른다고 가정하고 표준편차만으로 구한다. 정규분포의 99% 분위수 z = 2.3263 을 쓴다.

VaR(99%, 1일) = z × σ_일간 × 포지션 금액,   z = 2.3263

자산이 여러 개면 σ 자리에 포트폴리오 표준편차 √(wᵀΣw) 가 들어간다. 여기서 w 는 자산별 금액 벡터, Σ 는 수익률의 공분산 행렬이다. 선형대수로 보면 이차형식 하나를 계산하는 것이라 자산이 수천 개여도 빠르다. 옵션처럼 비선형인 상품은 델타로 선형 근사(델타-노멀)하거나 감마까지 넣어(델타-감마) 근사한다.

2. 역사적 시뮬레이션

분포를 가정하지 않는다. 과거 250영업일의 실제 수익률을 오늘 포지션에 그대로 다시 적용해 250개의 손익 시나리오를 만들고, 그중 손실이 큰 쪽 1% 지점을 고른다. 250 × 1% = 2.5 이므로 보통 세 번째로 큰 손실(또는 2, 3번째 사이 보간)을 쓴다. 두꺼운 꼬리와 자산 간 상관이 데이터에 이미 들어 있다는 게 장점이고, 과거 250일에 없던 사건은 못 본다는 게 단점이다.

3. 몬테카를로 시뮬레이션

위험요인(지수, 금리, 변동성)의 확률모형을 정하고 난수로 수만 개 시나리오를 만든 뒤, 시나리오마다 포지션을 완전재평가한다. 옵션 가격 공식을 다시 돌려 손익을 구하니 비선형성이 정확히 반영된다. 대신 시나리오 수 × 상품 수만큼 평가를 돌려야 해서 계산이 가장 무겁다.

예시 숫자: 지수 1억 원과 풋 매도

오늘은 두 가지 포지션을 가정한다. 하나는 코스피200 같은 지수에 1억 원을 산 선형 포지션, 다른 하나는 같은 명목 1억 원어치의 3개월 등가격(ATM) 풋 옵션을 판 비선형 포지션이다. 연 변동성은 30% 로 가정해 일간으로는 30% / √252 = 1.890% 다. 실제 과거 수익률 대신 꼬리가 두꺼운 t분포(자유도 4)로 만든 가상 데이터 250일을 쓴다. 무위험금리는 2026년 11월 9일 CD 91일물 금리 연 3.36%(금융투자협회 기준, 핀포인트뉴스 보도)를 썼다.

손으로 먼저 해 보면, 지수 1억 원의 1일 99% VaR 는 2.3263 × 1.890% × 1억 원 ≈ 440만원이다. 11월 17일 같은 −2.59% 하락이면 손실은 259만원이니 VaR 안쪽이다. 참고로 #13에서 본 2026년 11월 6일 VKOSPI 64.74(SBS Biz)를 그대로 연 변동성으로 넣으면 일간 4.08%, 1일 99% VaR 는 1억 원당 약 949만원(9.49%)까지 커진다. 어떤 변동성을 넣느냐가 결과를 좌우한다.

파이썬과 QuantLib으로 확인

import numpy as np
import QuantLib as ql
from scipy.stats import norm, t

N = 100_000_000           # 포지션 1억 원 (가정)
sig_y = 0.30              # 연 변동성 30% (가정)
sig_d = sig_y/np.sqrt(252)
z99 = norm.ppf(0.99)
print(f"[0] 일간 변동성 {sig_d*100:.3f}%, z(99%) = {z99:.4f}")

# [1] 가정 수익률 250일: 꼬리가 두꺼운 t분포(자유도 4), 일간 변동성 sig_d 로 맞춤
rng = np.random.default_rng(14)
nu = 4
ret = t.rvs(nu, size=250, random_state=rng) * sig_d / np.sqrt(nu/(nu-2))
pnl = N*ret
print(f"\n[1] 가정 데이터 250일: 표본 일간 변동성 {ret.std(ddof=1)*100:.3f}%, 최저 {ret.min()*100:.2f}%")
# (a) 분산-공분산(정규) : 표본 표준편차 사용
var_p = z99*ret.std(ddof=1)*N
# (b) 역사적 시뮬레이션: 손실 하위 1% (250일 중 2~3번째)
loss = -pnl
srt = np.sort(loss)[::-1]
var_h = srt[2]   # 250일 x 1% = 2.5 -> 3번째로 큰 손실
print(f"  손실 큰 순서 1~4위(만원): {[round(x/1e4) for x in srt[:4]]}")
# (c) 몬테카를로: 표본 변동성 정규분포로 10만 개
sim = rng.standard_normal(100_000)*ret.std(ddof=1)
var_m = np.quantile(-N*sim, 0.99)
print(f"  분산-공분산 VaR99 1일 : {var_p/1e4:,.0f}만원")
print(f"  역사적 시뮬레이션 VaR99: {var_h/1e4:,.0f}만원")
print(f"  몬테카를로(정규) VaR99 : {var_m/1e4:,.0f}만원")
# ES 97.5%
k = int(np.ceil(250*0.025))
es_h = srt[:k].mean()
es_p = N*ret.std(ddof=1)*norm.pdf(norm.ppf(0.975))/0.025
print(f"  ES97.5 역사적(상위 {k}개 평균): {es_h/1e4:,.0f}만원, 정규 ES97.5: {es_p/1e4:,.0f}만원")

# [2] 10일 VaR (제곱근 규칙)
print(f"\n[2] 10일 VaR99 = 1일 x sqrt(10): {var_p*np.sqrt(10)/1e4:,.0f}만원")

# [3] 옵션 포지션: 3개월 ATM 풋 매도, 명목 1억 (지수 100 기준 100만 계약단위, 가정)
S0, K, r, T = 100.0, 100.0, 0.0336, 91/365
qty = -N/S0
today = ql.Date(24, 11, 2026); ql.Settings.instance().evaluationDate = today
dc = ql.Actual365Fixed(); cal = ql.NullCalendar()
spot = ql.SimpleQuote(S0)
proc = ql.BlackScholesMertonProcess(ql.QuoteHandle(spot),
        ql.YieldTermStructureHandle(ql.FlatForward(today, 0.0, dc)),
        ql.YieldTermStructureHandle(ql.FlatForward(today, r, dc)),
        ql.BlackVolTermStructureHandle(ql.BlackConstantVol(today, cal, sig_y, dc)))
opt = ql.VanillaOption(ql.PlainVanillaPayoff(ql.Option.Put, K), ql.EuropeanExercise(today+91))
opt.setPricingEngine(ql.AnalyticEuropeanEngine(proc))
p0, de, ga = opt.NPV(), opt.delta(), opt.gamma()
print(f"\n[3] 풋 1단위 가격 {p0:.4f}, 델타 {de:.4f}, 감마 {ga:.5f} -> 포지션 가치 {qty*p0/1e4:,.0f}만원")

def bs_put(S, Tt):
    d1 = (np.log(S/K)+(r+0.5*sig_y**2)*Tt)/(sig_y*np.sqrt(Tt)); d2 = d1-sig_y*np.sqrt(Tt)
    return K*np.exp(-r*Tt)*norm.cdf(-d2) - S*norm.cdf(-d1)
print(f"  numpy BS 확인: {bs_put(S0, T):.4f}")
for h, lab in [(1, "1일"), (10, "10일")]:
    dS = S0*rng.standard_normal(200_000)*sig_d*np.sqrt(h)
    Th = T - h/365
    full = qty*(bs_put(S0+dS, Th) - bs_put(S0, T))
    dn = qty*de*dS
    dg = qty*(de*dS + 0.5*ga*dS**2)
    v = lambda x: np.quantile(-x, 0.99)/1e4
    print(f"  {lab} VaR99  델타-노멀 {v(dn):,.0f}  델타-감마 {v(dg):,.0f}  완전재평가 {v(full):,.0f} (만원)")
# 11/17 하락폭 -2.59% 를 그대로 넣으면
for m in [-0.0259, -0.05]:
    S1 = S0*(1+m)
    print(f"  지수 {m*100:+.2f}%: 지수 1억 손익 {N*m/1e4:,.0f}만원, 풋 매도 손익 {qty*(bs_put(S1, T-1/365)-bs_put(S0, T))/1e4:,.0f}만원")

결과 읽기

[1] 선형 포지션. 가상 데이터의 표본 일간 변동성은 2.023% 로 가정한 1.890% 보다 조금 높게 나왔다. 이 σ 로 구한 분산-공분산 VaR 는 471만원이고, 같은 σ 의 정규분포로 10만 번 돌린 몬테카를로도 471만원으로 같다. 정규 가정 위의 두 방법이니 당연한 결과다. 역사적 시뮬레이션은 손실 큰 순서 1007, 664, 494, 483만원 중 세 번째인 494만원이다. 차이는 ES 에서 더 크게 벌어진다. 상위 7개(250 × 2.5% = 6.25, 올림) 평균인 역사적 ES 는 562만원인데, 정규분포 ES 는 473만원이다. 최악의 날 −10.07% 같은 꼬리를 정규분포는 못 담는다.

[2] 10일 VaR. 수익률이 날마다 독립이면 분산이 기간에 비례하니 σ 는 √기간 에 비례한다. 1일 VaR 에 √10 을 곱해 1,488만원이다. 변동성이 몰려 다니는(변동성 군집) 실제 시장에서는 이 제곱근 규칙이 꼬리 위험을 과소평가할 수 있다.

[3] 비선형 포지션. 풋 1단위(지수 100 기준) 가격은 5.5376, 델타 −0.4480, 감마 0.02641 이고 직접 짠 numpy 블랙숄즈 값과 소수 넷째 자리까지 같다. 풋을 팔았으니 포지션 델타는 +0.448 × 100만 단위, 지수 약 4,480만원어치를 산 것과 비슷하다. 1일에서는 델타-노멀 197만원, 델타-감마 223만원, 완전재평가 221만원으로 델타만 쓰면 약 11% 작게 나온다. 10일로 늘리면 델타-노멀 622만원, 완전재평가 868만원으로 델타 근사가 약 28% 작다(완전재평가가 약 40% 크다). 풋을 팔면 포지션 감마가 음수라 지수가 떨어질수록 델타가 커지며 손실이 가속되는데, 선형 근사는 이걸 못 본다. 실제로 −2.59% 에서는 풋 매도 손실이 122만원이지만 −5% 에서는 255만원으로, 하락폭이 약 2배일 때 손실은 2배 넘게 늘었다.

리스크관리에서 보는 것들

VaR 를 계산했으면 맞는지 확인해야 한다. 백테스팅은 지난 250일 동안 실제 손실이 그날의 99% VaR 를 넘은 횟수를 센다. 기대값은 2.5회이고, 바젤 기준은 넘은 횟수가 4회 이하면 녹색, 5~9회면 황색, 10회 이상이면 적색 구간으로 보고 자본 가산을 붙인다. 그리고 VaR 가 보지 못하는 영역은 스트레스 테스트로 메운다. "지수 −10%, 변동성 +20%p" 같은 시나리오를 직접 넣어 완전재평가하는 것이다. 오늘 [3] 의 마지막 두 줄이 가장 단순한 형태의 스트레스 테스트다.

VaR 에는 수학적인 약점도 있다. 두 포지션을 합친 VaR 가 각각의 VaR 합보다 클 수 있다(준가법성 위반). 분산 투자를 했는데 위험 숫자가 커지는 이상한 일이 생길 수 있다는 뜻이다. ES 는 이 성질을 지켜서 규제가 ES 로 옮겨 갔다.

자주 묻는 질문

Q. 95% 와 99% 중 무엇을 쓰나?

목적에 따라 다르다. 내부 한도 관리에는 95% 를 쓰기도 하고, 규제 자본 계산은 전통적으로 99%, 10일 기준을 썼다. 정규분포라면 95% 의 z 는 1.6449, 99% 는 2.3263 이라 약 1.41배 차이다. 꼬리가 두꺼운 분포에서는 그 비율이 더 커진다.

Q. VaR 가 500만원이면 최대 손실이 500만원인가?

아니다. 100일 중 하루 정도는 500만원보다 더 잃을 수 있다는 뜻이고, 그날 얼마를 잃는지는 VaR 가 말하지 않는다. 오늘 예에서 역사적 VaR 는 494만원이었지만 최악의 날 손실은 1,007만원이었다. 그래서 ES 와 스트레스 테스트를 같이 본다.

Q. 세 방법 중 무엇이 가장 정확한가?

정답은 없다. 선형 포지션이 대부분이면 분산-공분산법이 빠르고 충분하다. 옵션이 많으면 완전재평가가 가능한 역사적 시뮬레이션이나 몬테카를로가 필요하다. 역사적 시뮬레이션은 데이터 기간 선택에, 몬테카를로는 모형 가정에 결과가 묶인다는 점을 같이 기억해야 한다.

오늘의 한 줄

VaR 는 손실 분포의 99% 분위수이고, 분산-공분산·역사적 시뮬레이션·몬테카를로로 구한다. 가정한 지수 1억 원 포지션의 1일 99% VaR 는 471~494만원이었지만 꼬리 평균(ES 97.5%)은 정규 473만원 대 역사적 562만원으로 갈렸고, 풋 매도는 10일 기준 델타 근사가 완전재평가보다 약 28% 작았다. 다음 일기 #15는 헐-화이트 금리 모형.
