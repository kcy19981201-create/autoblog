--- title: 퀀트 공부 일기 #7 - 몬테카를로 시뮬레이션 labels: 퀀트 공부 일기, 금융공학, 옵션 ---

2026년 10월 29일.

#5에서 옵션 가격은 위험중립 측도 아래 할인된 만기 손익의 기댓값이라고 정리했다. 블랙숄즈는 그 기댓값을 적분으로 끝까지 풀어낸 경우다. 그런데 손익이 경로 전체에 의존하거나 기초자산이 여러 개면 적분이 닫힌 형태로 안 풀린다. 그때 쓰는 가장 단순한 방법이 몬테카를로 시뮬레이션이다. 위험중립 세계의 주가 경로를 난수로 많이 만들고, 각 경로의 할인 손익을 평균 낸다. 오늘은 해석해가 있는 유럽형 콜로 정확도를 확인하고, 분산 감소 기법 두 가지, 공식이 없는 아시안 옵션, 그리고 #6에서 예고한 몬테카를로 델타까지 정리한다.

직관: 기댓값을 표본평균으로 바꾼다

가격 공식은 V = e^(−rT)·E^Q[ payoff ] 하나다. 기댓값을 직접 계산할 수 없으면, 같은 분포에서 표본을 N개 뽑아 평균을 내면 된다. 큰수의 법칙이 표본평균이 참값으로 수렴한다는 것을 보장하고, 중심극한정리가 그 오차의 크기를 알려 준다.

  • 표본평균의 표준오차는 s/√N 이다(s 는 할인 손익의 표본표준편차). 경로 수를 100배 늘려야 오차가 10분의 1로 줄어든다.
  • 그래서 몬테카를로 결과는 숫자 하나가 아니라 추정치 ± 1.96 × 표준오차의 95% 신뢰구간으로 읽어야 한다.
  • 오차가 1/√N 으로 줄어드는 속도는 기초자산 개수(차원)와 무관하다. 격자를 까는 방법(이항 트리, 유한차분)은 차원이 늘면 계산량이 폭발하는데, 몬테카를로는 그렇지 않다. 다자산·경로의존 상품에서 몬테카를로가 기본 도구가 된 이유다.

수식: 주가 경로를 만드는 법

블랙숄즈 세계에서 위험중립 주가는 기하 브라운 운동을 따른다.

dS = r·S·dt + σ·S·dW

W 는 브라운 운동이고, dW 는 평균 0, 분산 dt 인 정규분포 증분이다. 이 확률미분방정식은 이토 보조정리로 ln S 에 대해 풀 수 있다. f = ln S 로 두면 이토 공식의 2차 항 (1/2)·f''·(dS)² = −(1/2)·σ²·dt 가 붙어서

d(ln S) = (r − σ²/2)·dt + σ·dW
S_T = S_0 · exp( (r − σ²/2)·T + σ·√T·Z ),   Z ~ N(0, 1)

가 된다. 드리프트에서 σ²/2 를 빼는 이유가 이 2차 항이다. 빼지 않으면 E[S_T] 가 S_0·e^(rT) 보다 커져서 할인한 주가가 마팅게일이 아니게 되고, #2에서 본 무차익 조건이 깨진다.

만기 값만 필요한 유럽형은 Z 하나로 S_T 를 바로 뽑는다. 경로 중간값이 필요한 상품은 시간을 dt 로 나누고 같은 식을 매 구간 반복한다. 기하 브라운 운동은 이렇게 쪼개도 오차가 없는 정확한 해라서, 이산화 오차는 관측 시점 사이를 보간할 필요가 있을 때만 생긴다.

오차를 줄이는 방법도 두 가지만 정리한다.

  • 대조변수(antithetic variates): Z 를 하나 뽑으면 −Z 도 같이 쓴다. 두 경로의 손익이 음의 상관을 가지면 평균의 분산이 줄어든다.
  • 통제변수(control variate): 기댓값을 정확히 아는 변수 X 를 같이 시뮬레이션하고, Y − b·(X − E[X]) 를 평균 낸다. 할인된 S_T 는 기댓값이 S_0 라는 것을 알기 때문에 X 로 쓰기 좋다. 최적의 b 는 Cov(Y, X)/Var(X) 로, 결국 Y 를 X 에 회귀한 기울기다. 분산은 (1 − ρ²) 배로 줄어든다(ρ 는 Y 와 X 의 상관계수).

예시 숫자: 2026년 10월 28일 코스피로 계산

2026년 10월 28일 코스피는 6.63% 오른 6,012.44에 마감했다. 10거래일 만에 6,000선을 되찾았다. 금리는 지난 일기와 같이 10월 22일 동결된 기준금리 연 3.00%를 연속복리로 간주해 쓴다. 같은 날 국고채 3년물은 연 3.799% 였다. 행사가 6,000, 만기 91일, 변동성 연 30%, 배당 없음은 가정이다. 실제 지수옵션의 기초자산은 코스피200이니 숫자 감각을 위한 예시다.

하루 6.63% 상승이 이 모형에서 얼마나 드문지도 마지막 줄에서 계산한다. 연 30% 변동성을 거래일 252일로 나누면 일간 표준편차는 약 1.89% 다.

파이썬과 QuantLib으로 확인

import numpy as np
import QuantLib as ql
from math import log, sqrt, exp, erf

def N(x): return 0.5*(1+erf(x/sqrt(2)))

# 2026-10-28 코스피 종가 6,012.44 / 기준금리 3.00% (2026-10-22 동결)
S0, K, r, sigma, T = 6012.44, 6000.0, 0.03, 0.30, 91/365   # 행사가·만기·변동성은 가정

# 0) 블랙숄즈 정답
d1 = (log(S0/K) + (r + 0.5*sigma**2)*T) / (sigma*sqrt(T)); d2 = d1 - sigma*sqrt(T)
bs = S0*N(d1) - K*exp(-r*T)*N(d2)
print(f"블랙숄즈 콜 = {bs:,.2f}")

# 1) 기본 몬테카를로: S_T = S0*exp((r-σ²/2)T + σ√T Z)
rng = np.random.default_rng(20261028)
def mc_call(n, rng):
    Z = rng.standard_normal(n)
    ST = S0*np.exp((r-0.5*sigma**2)*T + sigma*sqrt(T)*Z)
    pay = np.exp(-r*T)*np.maximum(ST-K, 0)
    return pay.mean(), pay.std(ddof=1)/sqrt(n)
for n in [1_000, 10_000, 100_000, 1_000_000]:
    m, se = mc_call(n, rng)
    print(f"N={n:>9,}: 가격={m:,.2f}  표준오차={se:.2f}  95%구간=[{m-1.96*se:,.2f}, {m+1.96*se:,.2f}]")

# 2) 분산 감소: 대조변수(antithetic), 통제변수(control variate, 기초자산 S_T)
n = 100_000
rng = np.random.default_rng(7)
Z = rng.standard_normal(n)
drift, vol = (r-0.5*sigma**2)*T, sigma*sqrt(T)
ST = S0*np.exp(drift + vol*Z)
pay = np.exp(-r*T)*np.maximum(ST-K, 0)
print(f"기본(N=100,000): 가격={pay.mean():,.2f} 표준오차={pay.std(ddof=1)/sqrt(n):.2f}")
n2 = n//2
Za = Z[:n2]
STp = S0*np.exp(drift + vol*Za); STm = S0*np.exp(drift - vol*Za)
pa = 0.5*np.exp(-r*T)*(np.maximum(STp-K,0)+np.maximum(STm-K,0))
print(f"대조변수(50,000쌍): 가격={pa.mean():,.2f} 표준오차={pa.std(ddof=1)/sqrt(n2):.2f}")
X = np.exp(-r*T)*ST            # 할인된 S_T, 기댓값 = S0
b = np.cov(pay, X)[0,1]/X.var(ddof=1)
pc = pay - b*(X - S0)
print(f"통제변수(b={b:.3f}): 가격={pc.mean():,.2f} 표준오차={pc.std(ddof=1)/sqrt(n):.2f}")

# 3) 공식이 없는 상품: 산술평균 아시안 콜 (매주 13회 관측)
steps = 13; dt = T/steps; npath = 200_000
rng = np.random.default_rng(11)
Zs = rng.standard_normal((npath, steps))
logS = np.log(S0) + np.cumsum((r-0.5*sigma**2)*dt + sigma*sqrt(dt)*Zs, axis=1)
avg = np.exp(logS).mean(axis=1)
pas = np.exp(-r*T)*np.maximum(avg-K, 0)
print(f"아시안 콜(주1회 13관측, 경로 200,000): 가격={pas.mean():,.2f} 표준오차={pas.std(ddof=1)/sqrt(npath):.2f}")

# QuantLib 몬테카를로 엔진으로 같은 아시안 확인
today = ql.Date(28, 10, 2026); ql.Settings.instance().evaluationDate = today
dc = ql.Actual365Fixed()
spot = ql.QuoteHandle(ql.SimpleQuote(S0))
rts = ql.YieldTermStructureHandle(ql.FlatForward(today, r, dc, ql.Continuous))
qts = ql.YieldTermStructureHandle(ql.FlatForward(today, 0.0, dc, ql.Continuous))
vts = ql.BlackVolTermStructureHandle(ql.BlackConstantVol(today, ql.NullCalendar(), sigma, dc))
proc = ql.BlackScholesMertonProcess(spot, qts, rts, vts)
fix = [today + 7*(i+1) for i in range(13)]
asian = ql.DiscreteAveragingAsianOption(ql.Average.Arithmetic, 0.0, 0, fix,
            ql.PlainVanillaPayoff(ql.Option.Call, K), ql.EuropeanExercise(fix[-1]))
eng = ql.MCDiscreteArithmeticAPEngine(proc, "pseudorandom", requiredSamples=200_000, seed=42)
asian.setPricingEngine(eng)
print(f"QuantLib MC 아시안 콜: 가격={asian.NPV():,.2f} 오차추정={asian.errorEstimate():.2f}")
asian.setPricingEngine(ql.AnalyticDiscreteGeometricAveragePriceAsianEngine(proc))
print(f"(참고) 기하평균 아시안 해석해: {asian.NPV():,.2f}")

# 4) 몬테카를로 델타: 같은 난수(CRN) vs 다른 난수
h = S0*0.01; n = 100_000
def price_with(s, Z):
    return (np.exp(-r*T)*np.maximum(s*np.exp(drift+vol*Z)-K, 0)).mean()
deltas_crn, deltas_ind = [], []
for i in range(20):
    rg = np.random.default_rng(100+i)
    Z1 = rg.standard_normal(n); Z2 = rg.standard_normal(n)
    deltas_crn.append((price_with(S0+h, Z1) - price_with(S0-h, Z1))/(2*h))
    deltas_ind.append((price_with(S0+h, Z1) - price_with(S0-h, Z2))/(2*h))
print(f"공식 델타 = {N(d1):.4f}")
print(f"같은 난수 델타: 평균={np.mean(deltas_crn):.4f} 표준편차={np.std(deltas_crn, ddof=1):.4f}")
print(f"다른 난수 델타: 평균={np.mean(deltas_ind):.4f} 표준편차={np.std(deltas_ind, ddof=1):.4f}")

# 5) 하루 6.63% 상승은 σ=30% 가정에서 얼마나 드문가
d = sigma*sqrt(1/252)
z = log(1.0663)/d
print(f"일간 변동성={d:.4%}, 6.63% 상승은 약 {z:.2f} 표준편차, 확률≈{1-N(z):.6f}")

출력에서 읽은 것

  • 표준오차는 정확히 1/√N 으로 줄어든다. 경로 1,000개에서 18.54, 1만 개에서 5.80, 10만 개에서 1.86, 100만 개에서 0.59. 10배 늘릴 때마다 약 √10 ≈ 3.16 배씩 줄었다. 100만 개를 돌려도 블랙숄즈 정답 386.56 과 0.24 차이가 난다.
  • 1,000개 결과 352.30 은 34 이상 틀렸지만, 신뢰구간 [315.96, 388.65] 은 정답을 포함한다. 몬테카를로 숫자는 구간과 같이 보고해야 한다는 뜻이다. 구간 없이 352.30 만 보면 모형이 틀렸다고 착각할 수 있다.
  • 통제변수가 가장 잘 듣는다. 같은 10만 개 난수에서 표준오차가 1.87 → 0.85 로 절반 이하가 됐다. 분산으로는 약 4.8배 줄어든 것이라, 기본 방법으로 같은 정밀도를 내려면 경로가 약 48만 개 필요하다. 등가격 콜은 S_T 와 상관이 높아서 효과가 크다.
  • 대조변수는 효과가 작다. 같은 손익 계산 횟수(10만 번)에서 표준오차 1.87 → 1.42. 콜 손익은 Z 에 대해 한쪽만 꺾인 함수라서 Z 와 −Z 의 손익 상관이 강하게 음수가 되지 않는다. 손익이 Z 에 대해 대칭에 가까울수록 효과가 사라진다.
  • 아시안 콜은 일반 콜보다 훨씬 싸다. 13번 관측한 평균은 만기 한 시점의 주가보다 덜 흔들려서, 가격이 236 근처로 유럽형 386.56 의 약 61% 다. 직접 짠 코드(236.47)와 QuantLib 엔진(236.99)이 서로의 표준오차 0.79 안쪽에서 맞는다. 기하평균 버전은 해석해(230.56)가 있어서, 이걸 통제변수로 쓰는 게 아시안 옵션 몬테카를로의 정석이다.
  • 몬테카를로 델타는 같은 난수를 써야 한다. 공식 델타 0.5551 에 대해, 범프 전후에 같은 난수를 쓰면 20번 반복한 표준편차가 0.0018 인데 다른 난수를 쓰면 0.0239 로 13배 넘게 커진다. 차분 분모 2h 가 작아서 두 가격의 잡음이 그대로 증폭되기 때문이다.
  • 어제 같은 하루는 모형 안에서 매우 드물다. 연 30% 변동성이면 6.63% 상승은 약 3.40 표준편차이고, 정규분포로 계산한 확률은 하루 0.000341, 대략 2,900 거래일에 한 번이다. 실제 수익률은 꼬리가 두꺼워서 이보다 자주 일어난다. 정규분포 가정이 꼬리 위험을 과소평가한다는 것은 리스크관리에서 계속 나오는 주제다.

리스크관리에서 몬테카를로를 쓰는 곳

석사 때 배운 범위에서 몬테카를로가 등장하는 자리를 정리하면 이렇다.

  • 경로의존·다자산 상품 평가: 아시안, 배리어, 여러 기초자산이 걸린 상품처럼 트리나 공식이 어려운 경우. 다자산이면 상관된 정규난수가 필요한데, 상관행렬을 촐레스키 분해(대칭 양정치 행렬을 하삼각행렬 L 과 그 전치의 곱 L·Lᵀ 로 쪼개는 것)해서 독립 정규난수 벡터에 L 을 곱해 만든다.
  • 민감도: 범프 앤 리밸류를 쓰되 반드시 같은 난수로 계산한다. 위 출력이 그 이유다.
  • VaR 같은 손익 분포 추정: 시장 변수를 시뮬레이션해 포트폴리오를 전체 재평가하고, 손익 분포의 분위수를 읽는다. 로드맵 뒤쪽 VaR 일기에서 다시 다룬다.

한계도 분명하다. 수렴이 느려서 정밀도를 한 자리 올리려면 계산량이 100배 든다. 그리고 조기행사(미국형)처럼 "지금 행사할지"를 판단해야 하는 상품은 경로를 앞에서 뒤로 만드는 구조와 맞지 않아서, 회귀를 섞은 최소제곱 몬테카를로 같은 별도 기법이 필요하다. 저차원이고 조기행사가 있는 상품은 #4의 트리나 다음 일기의 유한차분법이 더 효율적이다.

자주 묻는 질문

Q. 경로는 몇 개면 충분한가?

정해진 숫자는 없다. 원하는 오차를 정하고 표준오차로 역산한다. 위 예시에서 표준오차를 0.5 로 맞추려면 기본 방법으로 약 140만 개(18.54²×1,000/0.5²)가 필요하다. 분산 감소를 붙이면 그 수가 크게 줄어든다.

Q. 의사난수 대신 다른 수열을 쓰면?

소볼 수열 같은 저불일치 수열(준몬테카를로)은 공간을 더 고르게 채워서, 매끄러운 문제에서는 오차가 1/N 에 가깝게 줄어든다. 대신 표본이 독립이 아니라서 위처럼 표본표준편차로 오차를 바로 계산할 수 없다. QuantLib 엔진의 "pseudorandom" 인자를 "lowdiscrepancy" 로 바꾸면 쓸 수 있다.

Q. 실제 확률(P)로 시뮬레이션하면 안 되나?

가격을 구할 때는 안 된다. #5에서 정리한 대로 가격은 위험중립 측도 Q 아래 기댓값이라 드리프트에 r 을 넣는다. 반대로 VaR 처럼 실제 세계에서 손실이 얼마나 날지를 볼 때는 P 아래 시뮬레이션이 맞다. 같은 몬테카를로라도 무엇을 구하느냐에 따라 측도가 달라진다.

오늘의 한 줄

몬테카를로는 기댓값을 표본평균으로 바꾸고, 결과는 항상 신뢰구간과 같이 읽는다. 오차는 1/√N 이라 분산 감소가 실력이고, 민감도는 같은 난수로 잰다. 다음 일기 #8은 편미분방정식을 격자 위에서 푸는 유한차분법(FDM).
