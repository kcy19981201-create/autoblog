2026년 10월 24일.

#2에서 선도를 끝으로 할인계수 하나로 닫히는 상품은 일단 정리했다. 오늘은 할인을 여러 번 하는 상품, 쿠폰 채권이다. 결론부터 적으면, 채권 가격은 현금흐름 각각의 현재가치 합이고, 금리가 조금 움직일 때 가격이 몇 % 움직이는지는 수정 듀레이션 한 숫자로 거의 맞힐 수 있다. 금리가 크게 움직이면 그 오차를 볼록성(convexity)이 메운다.

직관: 채권은 할인된 현금흐름 묶음이다

쿠폰 채권은 정해진 날짜에 이자를 주고 만기에 원금을 돌려주는 약속이다. 그러니 #1의 현재가치를 현금흐름마다 한 번씩 적용해 더하면 가격이 된다. 이때 모든 현금흐름에 같은 금리 하나를 적용해 시장 가격과 맞추는 금리가 만기수익률(YTM)이다.

금리가 오르면 각 현금흐름의 할인계수가 작아지니 가격이 내려간다. 여기까지는 채권 금리와 가격 관계 글에서 쉽게 풀어둔 내용이다. 오늘 궁금한 건 그다음, "얼마나" 내려가느냐다. 멀리 있는 현금흐름일수록 할인을 여러 번 받으니 금리 변화에 더 크게 흔들린다. 그래서 현금흐름이 평균적으로 얼마나 멀리 있는지가 곧 금리 민감도가 된다. 그 평균 거리가 듀레이션이다.

예시 숫자: 2026년 10월 23일 국고채 금리로

2026년 10월 23일 서울 채권시장 국고채 금리는 3년 3.803%, 5년 3.948%, 10년 4.097%로 마감했다(1년 3.668%, 2년 3.760%, 전일 대비 일제히 하락). 이 금리를 반기복리 만기수익률로 보고, 오늘 발행했다고 가정한 쿠폰 연 3.5%(6개월마다 지급), 액면 10,000원짜리 3년 채권을 평가한다. 쿠폰이 만기수익률보다 낮으니 액면 아래에서 거래될 것이다.

  • 6개월마다 쿠폰 175원, 6번째(3년)에 원금 10,000원 추가
  • 반기 할인율 3.803% / 2 = 1.9015%
  • 가격 = Σ 현금흐름 / 1.019015^k = 9,914.86원

현금흐름별 현재가치는 171.73, 168.53, 165.39, 162.30, 159.27, 9,087.64원이다. 마지막 현금흐름이 가격의 91.66%를 차지한다. 쿠폰이 조금씩 앞당겨 들어오는 만큼, 평균 거리는 3년보다 살짝 짧다.

수식: 맥컬리 듀레이션, 수정 듀레이션, 볼록성

현금흐름 시점을 t_k(년), 금액을 CF_k, 반기복리 만기수익률을 y 라 하면

P(y) = Σ CF_k / (1 + y/2)^(2·t_k)

맥컬리 듀레이션  D_mac = Σ t_k · w_k ,  w_k = PV_k / P   (현재가치 비중)
수정 듀레이션    D_mod = D_mac / (1 + y/2)
볼록성          C = (1/P) · d²P/dy²

ΔP/P ≈ −D_mod · Δy + ½ · C · (Δy)²

마지막 줄이 핵심이다. 가격을 금리의 함수 P(y)로 보고 현재 금리 근처에서 테일러 전개한 것이다. 테일러 전개는 매끄러운 함수를 한 점 근처에서 다항식으로 근사하는 방법으로, f(y+Δy) ≈ f(y) + f′(y)Δy + ½f″(y)(Δy)² 이다. 1차 항의 계수를 가격으로 나눈 것이 −D_mod, 2차 항의 계수를 가격으로 나눈 것이 C 다. 그래서 수정 듀레이션은 "가격-금리 곡선의 기울기", 볼록성은 "그 곡선이 휘어진 정도"다.

맥컬리 듀레이션을 미분하면 수정 듀레이션이 나오는 이유도 짧게 적어둔다. (1 + y/2)^(−2t) 를 y 로 미분하면 −t · (1 + y/2)^(−2t−1) 이 된다. 이걸 모든 현금흐름에 대해 더하고 P 로 나누면 −D_mac / (1 + y/2) 이다. 복리 주기 하나만큼 나눠주는 게 "수정"의 정체다. #1 에서 연속복리를 쓰면 미분이 깔끔해진다고 적었는데, 연속복리라면 두 듀레이션이 같아진다.

실무에서 더 자주 보는 숫자는 DV01(금리 1bp, 즉 0.01%p 변화에 대한 가격 변화 금액)이다. 대략 P × D_mod × 0.0001 이다. 듀레이션은 비율이라 포지션 크기를 모르면 손익을 말할 수 없는데, DV01 은 원 단위라서 여러 채권을 그냥 더할 수 있다. #0 프롤로그에서 말한 민감도 산출의 가장 기본 형태가 이것이다.

파이썬과 QuantLib으로 확인

import numpy as np
import QuantLib as ql

# 2026-10-23 국고채 3년 3.803%, 10년 4.097% (반기복리 만기수익률로 간주)
today = ql.Date(23, 10, 2026)
ql.Settings.instance().evaluationDate = today
dc = ql.ActualActual(ql.ActualActual.Bond)

def make_bond(years, coupon):
    sch = ql.Schedule(today, today + ql.Period(years, ql.Years), ql.Period(ql.Semiannual),
                      ql.NullCalendar(), ql.Unadjusted, ql.Unadjusted,
                      ql.DateGeneration.Backward, False)
    return ql.FixedRateBond(0, 10_000, sch, [coupon], dc)

def report(name, bond, y):
    r = ql.InterestRate(y, dc, ql.Compounded, ql.Semiannual)
    P   = ql.BondFunctions.cleanPrice(bond, r)
    mac = ql.BondFunctions.duration(bond, r, ql.Duration.Macaulay)
    mod = ql.BondFunctions.duration(bond, r, ql.Duration.Modified)
    cvx = ql.BondFunctions.convexity(bond, r)
    dv01 = ql.BondFunctions.basisPointValue(bond, r)
    print(f"[{name}] 가격={P*100:,.2f}원 Mac={mac:.4f} Mod={mod:.4f} Cvx={cvx:.3f} DV01(액면 1억)={abs(dv01)*1e4:,.0f}원")
    for dy in [0.01, -0.01]:
        rr = ql.InterestRate(y+dy, dc, ql.Compounded, ql.Semiannual)
        P2 = ql.BondFunctions.cleanPrice(bond, rr)
        exact = (P2-P)/P
        d1 = -mod*dy
        d2 = d1 + 0.5*cvx*dy*dy
        print(f"  {dy*1e4:+.0f}bp: 실제 {exact*100:+.3f}%  듀레이션 {d1*100:+.3f}%  +볼록성 {d2*100:+.3f}%")
    return P, mac, mod

b3 = make_bond(3, 0.035)
b10 = make_bond(10, 0.035)
P3, mac3, mod3 = report("3년 쿠폰3.5%", b3, 0.03803)
report("10년 쿠폰3.5%", b10, 0.04097)

# 손으로 맥컬리 듀레이션: 현금흐름 가중평균 만기
y = 0.03803; c = 175.0
t = np.arange(1, 7) / 2
cf = np.full(6, c); cf[-1] += 10_000
pv = cf / (1 + y/2) ** (2*t)
print("현금흐름 PV:", np.round(pv, 2), "합계", round(pv.sum(), 2))
print("가중치:", np.round(pv/pv.sum(), 4))
print(f"수동 Mac={np.sum(t*pv)/pv.sum():.4f}, Mod={np.sum(t*pv)/pv.sum()/(1+y/2):.4f}")

# 무이표(제로) 3년 비교
z = ql.ZeroCouponBond(0, ql.NullCalendar(), 10_000, today + ql.Period(3, ql.Years))
report("3년 제로쿠폰", z, 0.03803)

출력에서 읽은 것

  • 수동 계산과 QuantLib 이 2.8733 으로 일치한다. 맥컬리 듀레이션은 정말로 현재가치 비중으로 가중한 평균 만기다. 쿠폰이 있는 3년 채권은 2.87년, 쿠폰이 없는 3년 제로쿠폰은 정확히 3.0000년이다. 중간에 돈을 돌려받을수록 평균 거리가 짧아진다.
  • 만기가 3년에서 10년으로 늘면 수정 듀레이션은 2.82에서 8.31로 뛴다. 금리 1%p 상승 시 3년물은 약 2.8%, 10년물은 약 7.9% 떨어진다. 액면 1억원 기준 DV01 은 27,952원 대 78,998원이다.
  • 금리가 크게 움직이면 듀레이션만으로는 틀린다. 10년물에서 +100bp 일 때 듀레이션 근사는 −8.307% 인데 실제는 −7.918% 다. 0.39%p 를 과대평가했다. 볼록성 항을 더하면 −7.904% 로 오차가 0.014%p 까지 줄어든다.
  • 금리 하락 때 이익이 상승 때 손실보다 크다. 10년물은 +100bp 에 −7.918%, −100bp 에 +8.725% 다. 가격-금리 곡선이 아래로 볼록해서 생기는 비대칭이고, 볼록성이 양수인 채권을 들고 있으면 이 비대칭을 공짜로 얻는 셈이다. 물론 시장은 그만큼 수익률을 덜 주는 식으로 값을 매긴다.

한계: 듀레이션이 가정하는 것

여기서 쓴 듀레이션은 모든 만기 금리가 똑같이 움직인다(평행 이동)는 가정 위에 있다. 만기수익률 하나를 움직였기 때문이다. 실제로는 단기와 장기 금리가 따로 움직인다. 10월 23일만 봐도 3년물은 3.7bp, 10년물은 5.5bp 내려 하락 폭이 달랐다.

그래서 리스크관리에서는 #1 에서 만든 할인곡선의 만기 구간(1년, 3년, 5년, 10년 …)을 하나씩 1bp 움직여 각각의 가격 변화를 재는 키 레이트 듀레이션(key rate duration) 또는 구간별 DV01 을 쓴다. 각 구간의 숫자를 더하면 대략 전체 DV01 이 된다. 이건 곡선 부트스트래핑을 제대로 다룰 때 다시 보려 한다. 또 하나, 듀레이션은 현금흐름이 고정이라고 가정한다. 콜옵션이 붙은 채권처럼 금리에 따라 현금흐름이 바뀌면 이 공식이 그대로 통하지 않고, 모형으로 가격을 다시 계산해서 민감도를 구해야 한다(유효 듀레이션).

자주 묻는 질문

Q. 듀레이션이 2.87년이면 2.87년 뒤에 뭔가 일어나나?

아니다. 시간 단위를 쓰지만 민감도 지표다. 다만 해석이 하나 있다. 금리가 한 번 평행 이동한 직후라면, 맥컬리 듀레이션만큼 보유했을 때 가격 손익과 재투자 수익 변화가 대략 상쇄된다. 이게 면역(immunization) 전략의 출발점이다.

Q. 수정 듀레이션과 DV01 중 뭘 봐야 하나?

둘 다 같은 정보다. 수정 듀레이션은 "가격의 몇 %", DV01 은 "몇 원"이다. 서로 다른 채권·스왑을 섞은 포트폴리오의 위험을 합칠 때는 원 단위인 DV01 이 편하다.

Q. 볼록성은 언제 신경 써야 하나?

오차가 (Δy)² 에 비례하니 금리 변화가 클수록, 그리고 만기가 길수록(C 가 클수록) 중요해진다. 위 예시에서 3년물 ±100bp 는 듀레이션만으로도 0.05%p 안쪽으로 맞지만, 10년물은 0.4%p 가까이 틀렸다.
