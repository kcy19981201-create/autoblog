--- title: 퀀트 공부 일기 #5 - 위험중립 가격결정과 블랙숄즈 labels: 퀀트 공부 일기, 금융공학, 옵션 ---

2026년 10월 27일.

#4에서 이항 트리를 잘게 쪼개면 블랙숄즈 값으로 수렴하는 걸 숫자로 봤다. 오늘은 그 극한을 연속시간에서 직접 다룬다. 결론부터 적으면, 블랙숄즈 가격은 주가의 기대수익률을 무위험이자율 r 로 바꿔 놓은 세계(위험중립 측도 Q)에서 만기 손익의 기댓값을 구하고, 그걸 r 로 할인한 값이다. 주가가 실제로 얼마나 오를 거라고 보든 가격은 바뀌지 않는다. 오늘은 이 문장을 수식과 몬테카를로로 각각 확인한다.

직관: 트리의 q 가 연속시간에서는 측도가 된다

이항 트리에서 옵션 가격은 C = e^(−rΔt)·[q·C_u + (1−q)·C_d] 였다. q 는 진짜 확률이 아니라, 주식의 기대수익률이 무위험이자율이 되도록 맞춘 계산용 확률이었다. 단계를 무한히 잘게 쪼개면 위·아래 두 갈래가 연속적인 주가 분포가 되고, q 는 "분포 전체를 다시 매긴 확률", 즉 확률측도가 된다. 실제 세계의 확률을 P, 계산용 세계의 확률을 Q 라고 부른다.

왜 이렇게 바꿔도 되는가는 #4 와 같은 논리다. 옵션을 주식과 무위험채권으로 매 순간 복제할 수 있으면, 옵션 가격은 복제 비용으로 정해진다. 복제 비용에는 주가가 오를 확률이 들어가지 않는다. 그러니 계산의 편의상 "모든 자산이 평균적으로 r 만큼만 버는 세계"를 가정해도 답이 같다. 이게 위험중립 가격결정이다. 투자자가 실제로 위험중립이라는 뜻이 아니라는 점을 따로 적어 둔다.

수식: 기하 브라운 운동과 이토의 보조정리

블랙숄즈는 주가가 다음 확률미분방정식(SDE)을 따른다고 가정한다.

dS_t = μ·S_t·dt + σ·S_t·dW_t        (실제 세계 P)
dS_t = r·S_t·dt + σ·S_t·dW̃_t        (위험중립 세계 Q)

읽는 법은 이렇다. 아주 짧은 시간 dt 동안 주가의 변화율 dS/S 는 평균 μ·dt 만큼 움직이고, 거기에 σ·dW 만큼의 잡음이 붙는다. W 는 브라운 운동으로, 겹치지 않는 구간의 증분이 서로 독립이고 길이 t 구간의 증분이 평균 0, 분산 t 인 정규분포를 따르는 연속 경로다. 그래서 dW 의 크기는 dt 가 아니라 √dt 수준이다. 트리에서 u = e^(σ√Δt) 로 √Δt 가 나왔던 이유가 이것이다.

이 SDE 를 풀려면 일반 미적분의 연쇄법칙을 그대로 쓸 수 없다. (dW)² 가 0 으로 사라지지 않고 dt 로 남기 때문이다. 테일러 전개에서 2차 항까지 살려야 하는데, 이걸 정리한 게 이토의 보조정리(Itô's lemma)다. f(S) = ln S 에 적용하면

d(ln S) = (1/S)·dS − (1/2)·(1/S²)·(dS)²
        = (μ − σ²/2)·dt + σ·dW

⇒ S_T = S_0 · exp[ (μ − σ²/2)·T + σ·√T·Z ],   Z ~ N(0,1)

로그주가가 정규분포, 주가는 로그정규분포다. #4 에서 중심극한정리로 얻은 결론과 같다. −σ²/2 항은 이토 보정이라 부르며, 이 덕분에 기댓값이 정확히 E[S_T] = S_0·e^(μT) 가 된다.

P 에서 Q 로 넘어가는 건 기르사노프 정리가 맡는다. dW̃ = dW + ((μ−r)/σ)·dt 로 잡으면 W̃ 가 Q 아래에서 다시 브라운 운동이 되고, 식에서 μ 가 r 로 바뀐다. (μ−r)/σ 는 위험 한 단위당 초과수익, 즉 위험의 시장가격이다. 측도를 바꾸면 이 값이 식에서 사라진다. 이제 Q 에서 기댓값을 계산하면 블랙숄즈 공식이 나온다.

C = e^(−rT)·E^Q[ max(S_T − K, 0) ] = S_0·N(d1) − K·e^(−rT)·N(d2)
P = K·e^(−rT)·N(−d2) − S_0·N(−d1)

d1 = [ ln(S_0/K) + (r + σ²/2)·T ] / (σ√T),   d2 = d1 − σ√T

N(·) 은 표준정규분포의 누적분포함수다. 두 항의 뜻이 깔끔하다. N(d2) 는 Q 아래에서 만기에 행사될 확률이고, K·e^(−rT)·N(d2) 는 "행사가를 낼 확률 × 행사가의 현재가치"다. N(d1) 은 콜의 델타, 즉 복제에 필요한 주식 수다. #4 의 Δ 가 연속시간에서 이렇게 생겼다.

예시 숫자: 2026년 10월 26일 코스피로 계산

2026년 10월 26일 코스피는 5,469.47에 마감했다(전 거래일 대비 1.46% 하락). 금리는 한국은행이 10월 22일 동결한 기준금리 연 3.00%를 연속복리로 간주해 쓰고, 같은 날 국고채 3년물 금리 연 3.789%로 바꿨을 때 가격이 얼마나 움직이는지도 본다. 행사가 5,470, 만기 91일, 변동성 연 30%, 배당 없음은 모두 가정이다. #4 와 마찬가지로 실제 지수옵션의 기초자산은 코스피200이니 숫자 감각을 위한 예시다.

파이썬과 QuantLib으로 확인

import numpy as np
import QuantLib as ql
from math import log, sqrt, exp, erf

def N(x):  # 표준정규 누적분포
    return 0.5*(1+erf(x/sqrt(2)))

# 2026-10-26 코스피 종가 5,469.47 / 기준금리 3.00% (2026-10-22 동결)
S0, K, r, sigma, T = 5469.47, 5470.0, 0.03, 0.30, 91/365   # 행사가·만기·변동성 30%는 가정

# 1) 블랙숄즈 공식 직접 계산
d1 = (log(S0/K) + (r + 0.5*sigma**2)*T) / (sigma*sqrt(T))
d2 = d1 - sigma*sqrt(T)
call = S0*N(d1) - K*exp(-r*T)*N(d2)
put  = K*exp(-r*T)*N(-d2) - S0*N(-d1)
print(f"d1={d1:.4f} d2={d2:.4f} N(d1)={N(d1):.4f} N(d2)={N(d2):.4f}")
print(f"공식: 콜={call:,.2f} 풋={put:,.2f}")
print(f"풋콜패리티: C-P={call-put:,.2f}  S-Ke^(-rT)={S0-K*exp(-r*T):,.2f}")

# 2) QuantLib 해석 엔진
today = ql.Date(26, 10, 2026); ql.Settings.instance().evaluationDate = today
dc = ql.Actual365Fixed()
spot = ql.SimpleQuote(S0)
rq = ql.SimpleQuote(r)
rts = ql.YieldTermStructureHandle(ql.FlatForward(today, ql.QuoteHandle(rq), dc, ql.Continuous))
qts = ql.YieldTermStructureHandle(ql.FlatForward(today, 0.0, dc, ql.Continuous))
volq = ql.SimpleQuote(sigma)
vts = ql.BlackVolTermStructureHandle(ql.BlackConstantVol(today, ql.NullCalendar(), ql.QuoteHandle(volq), dc))
proc = ql.BlackScholesMertonProcess(ql.QuoteHandle(spot), qts, rts, vts)
mat = today + 91
opt = ql.VanillaOption(ql.PlainVanillaPayoff(ql.Option.Call, K), ql.EuropeanExercise(mat))
opt.setPricingEngine(ql.AnalyticEuropeanEngine(proc))
print(f"QuantLib: 콜={opt.NPV():,.2f} 델타={opt.delta():.4f}")

# 3) 몬테카를로: 위험중립(Q, 기대수익률 r) vs 실제(P, 기대수익률 μ=10% 가정)
rng = np.random.default_rng(42)
n = 1_000_000
Z = rng.standard_normal(n)
for name, mu in [("Q (mu=r=3%)", r), ("P (mu=10%)", 0.10)]:
    ST = S0*np.exp((mu - 0.5*sigma**2)*T + sigma*sqrt(T)*Z)
    pay = np.maximum(ST-K, 0)
    disc = np.exp(-r*T)*pay
    se = disc.std()/sqrt(n)
    print(f"{name}: 평균 S_T={ST.mean():,.2f}  할인 기댓값={disc.mean():,.2f} (±{1.96*se:.2f})  행사 비율={np.mean(ST>K):.4f}")
print(f"S0*e^(rT)={S0*exp(r*T):,.2f}")

# 4) 금리 바꾸기: 기준금리 3.00% vs 국고채 3년 3.789% (2026-10-26)
for rr in [0.03, 0.03789]:
    rq.setValue(rr)
    print(f"r={rr:.3%}: 콜={opt.NPV():,.2f}")
rq.setValue(r)

# 5) 변동성 바꾸기
for s in [0.20, 0.30, 0.40]:
    volq.setValue(s)
    print(f"sigma={s:.0%}: 콜={opt.NPV():,.2f}")
volq.setValue(sigma)

# 6) 내재변동성: 시장가격이 400 이라면?
print(f"콜 400 의 내재변동성={opt.impliedVolatility(400.0, proc):.4f}")

출력에서 읽은 것

  • 공식, QuantLib, 몬테카를로가 같은 값을 준다. 공식과 QuantLib 은 345.85 로 일치하고, Q 아래 몬테카를로 100만 개는 345.97 로 95% 신뢰구간(±1.05) 안에 들어온다. 몬테카를로는 로드맵에서 따로 다룰 예정인데, 오늘은 "기댓값을 할인한다"는 정의를 그대로 코드로 옮긴 검산 도구로만 썼다.
  • Q 에서는 주가가 평균적으로 r 만큼만 오른다. Q 시뮬레이션의 평균 S_T 5,510.67 은 S_0·e^(rT) = 5,510.53 과 거의 같다. 위험중립 세계의 정의가 숫자로 보인다.
  • P 의 기댓값을 r 로 할인하면 틀린다. 기대수익률 10%를 넣고 같은 방식으로 계산하면 401.07 이 나온다. 이건 옵션 가격이 아니다. 실제 세계 기댓값을 쓰려면 할인율도 옵션의 위험에 맞게 바꿔야 하는데 그 할인율을 모른다. 위험중립 측도는 "할인율을 r 하나로 고정하는 대신 확률을 바꾸는" 방법이다.
  • N(d2) 는 Q 에서의 행사 확률이다. 공식의 N(d2) = 0.4898, Q 시뮬레이션의 행사 비율 0.4895 가 맞아떨어진다. P 에서의 행사 비율 0.5362 와는 다르다. N(d2) 를 "실제로 행사될 확률"로 읽으면 안 되는 이유다.
  • 풋콜패리티가 정확히 성립한다. C − P = 40.23 = S − K·e^(−rT). 모형과 상관없이 무차익만으로 나오는 관계라서, 평가 코드를 검산할 때 가장 먼저 확인하는 식이다.
  • 금리보다 변동성이 훨씬 크게 움직인다. 금리를 3.00%에서 국고채 3년물 3.789%로 바꾸면 콜이 345.85 → 351.11 로 5.26 오른다. 변동성을 20% → 40%로 바꾸면 237.72 → 453.89 로 두 배 가까이 된다. 만기가 짧은 옵션에서 금리 민감도는 작고 변동성 민감도는 크다. 이 기울기들이 다음에 다룰 그릭스다.

한계: 블랙숄즈가 가정하는 것과 내재변동성

공식이 깔끔한 대가로 가정이 많다. 변동성과 금리가 상수이고, 주가가 끊김 없이 움직이며(점프 없음), 거래비용 없이 연속적으로 복제 포트폴리오를 조정할 수 있다고 본다. 10월 26일처럼 코스피가 하루에 1.46%, 코스닥이 3.26% 빠지는 날에는 연속 조정이라는 가정이 특히 현실과 멀어진다.

실무에서는 공식을 거꾸로 쓰는 일이 많다. 시장 옵션 가격을 넣고 그 가격이 나오게 하는 σ 를 찾는 것이 내재변동성이다. 위 예시에서 같은 콜이 시장에서 400 에 거래된다면 내재변동성은 35.01% 다. σ 에 대한 가격 함수가 단조증가라서 해가 하나로 정해지고, QuantLib 은 이를 수치적인 근 찾기(브렌트 방법 같은 1차원 방정식 풀이)로 구한다. 행사가와 만기마다 내재변동성이 다르게 나오는 현상(스마일, 기간구조)은 블랙숄즈의 "σ 상수" 가정이 맞지 않는다는 시장의 신호이고, 이를 다루는 국소변동성·확률변동성 모형은 로드맵 뒤쪽 이야기다.

자주 묻는 질문

Q. 기대수익률 μ 가 공식에 없는데, 주가 전망은 옵션 가격과 무관한가?

복제가 가능한 블랙숄즈 세계에서는 그렇다. 전망은 이미 현재 주가 S_0 에 들어가 있고, 옵션 가격은 S_0, r, σ, K, T 만으로 정해진다. 다만 전망이 변동성에 대한 생각을 바꾼다면 σ 를 통해 가격에 영향을 준다. 시장에서 옵션 가격이 움직이는 건 대부분 이 경로다.

Q. 무위험이자율로 기준금리와 국고채 금리 중 무엇을 써야 하나?

원칙은 옵션 만기와 같은 만기의 무위험 금리를 할인곡선에서 읽어 쓰는 것이다(#1의 할인곡선). 오늘은 비교를 위해 기준금리와 국고채 3년물을 넣었을 뿐이고, 91일 만기라면 그 만기 근처 금리가 맞다. 위 결과처럼 짧은 만기에서는 이 선택이 가격에 주는 영향이 크지 않다.

Q. 미국형 옵션에도 블랙숄즈 공식을 쓸 수 있나?

배당 없는 미국형 콜은 조기행사가 이득이 없어서 유럽형과 같은 값이 된다(#4 에서 확인했다). 미국형 풋이나 배당이 있는 경우는 닫힌 공식이 없어서 이항 트리나 유한차분법 같은 수치해법을 쓴다.

오늘의 한 줄

블랙숄즈 가격은 기대수익률을 r 로 바꾼 세계에서 손익의 기댓값을 r 로 할인한 값이다. μ 는 사라지고 σ 가 가격을 좌우한다. 다음 일기 #6은 이 공식을 S, σ, T 로 미분해 보는 그릭스: 델타, 감마, 베가.
