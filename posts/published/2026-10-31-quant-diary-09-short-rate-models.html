2026년 10월 31일.

#4부터 #8까지는 주가가 확률적으로 움직이고 금리 r 은 상수였다. 블랙숄즈에 r = 3% 를 박아 넣고 끝냈다. 그런데 채권, 스왑, 금리옵션처럼 금리 자체가 기초자산인 상품에서는 그렇게 할 수 없다. 금리가 오늘 3% 라도 1년 뒤, 3년 뒤에는 다른 값이고, 그 불확실성이 곧 가격이다. 오늘은 금리를 확률과정으로 보는 가장 기본적인 틀인 단기금리 모형(short-rate model)을 정리한다. 바시첵 모형 하나를 끝까지 따라가고, CIR 모형과 비교한다. 전체 지도에서 어디쯤인지는 #0 프롤로그에 있다.

직관: 금리는 주가처럼 무한히 떠돌지 않는다

주가는 기하 브라운 운동으로 모형화했다. 오래 기다리면 주가의 분포는 점점 넓게 퍼진다. 금리는 성격이 다르다.

  • 평균 회귀(mean reversion): 금리가 많이 오르면 경기가 식고 중앙은행이 다시 내리고, 너무 낮으면 다시 올린다. 금리는 어떤 장기 수준 주변을 오간다.
  • 만기마다 금리가 다르다: 오늘 시장에는 3개월, 3년, 10년 금리가 동시에 있다. 모형은 하나의 확률과정에서 이 곡선 전체를 만들어 내야 한다.
  • 단기금리 하나로 곡선 전체를 설명: 단기금리 모형은 아주 짧은 기간의 금리 r(t) 하나만 확률과정으로 두고, 모든 만기의 채권 가격을 r 의 미래 경로에 대한 기댓값으로 만든다.

#1에서 할인계수 P(0, T) 를 시장에서 읽어 온 숫자로 다뤘다면, 오늘은 그 할인계수를 모형이 계산하는 값으로 바꾼다.

수식: 바시첵 모형

바시첵(Vasicek, 1977) 모형은 단기금리가 다음 확률미분방정식을 따른다고 둔다.

dr(t) = a·(b − r(t))·dt + σ·dW(t)
  • a: 회귀 속도. 금리가 장기 평균에서 벗어났을 때 돌아오는 힘의 세기다. ln2/a 가 "벗어난 정도가 절반으로 줄어드는 시간(반감기)"이다.
  • b: 장기 평균 수준.
  • σ: 단기금리 변동성. 주가 모형의 σ 가 비율(%)이었다면 여기서는 금리 수준과 상관없는 절대 크기(%p)다.

드리프트 항 a(b − r) 가 핵심이다. r 이 b 보다 높으면 음수가 되어 끌어내리고, 낮으면 양수가 되어 끌어올린다. 이런 과정을 오른슈타인-울렌벡 과정이라고 부른다.

이 SDE는 풀 수 있다. y(t) = e^(at)·r(t) 로 변수를 바꾸고 이토 공식을 쓰면 된다. 이토 공식은 확률과정의 함수를 미분할 때 일반 미분에 2차 항 (1/2)·f''·(dr)² 이 더 붙는다는 규칙인데, y 는 r 에 대해 1차 함수라 2차 항이 0이다. 그래서

d(e^(at)·r) = e^(at)·(a·b·dt + σ·dW)
r(t) = b + (r(0) − b)·e^(−at) + σ·∫₀ᵗ e^(−a(t−s)) dW(s)

마지막 적분은 정규분포를 따르는 확률변수다(브라운 운동 증분의 가중합). 따라서 r(t) 는 정규분포이고

평균 = b + (r(0) − b)·e^(−at)
분산 = σ²/(2a) · (1 − e^(−2at))

시간이 지나면 평균은 b 로, 분산은 σ²/(2a) 로 수렴한다. 주가 모형과 달리 분포가 무한히 퍼지지 않는다. 대신 정규분포라서 금리가 음수가 될 확률이 0이 아니다. 이게 바시첵의 대표적인 약점이다.

할인채 가격: 아핀 구조

만기 T 에 1원을 주는 할인채의 가격은 위험중립 측도에서

P(t, T) = E^Q[ exp(−∫ₜᵀ r(s) ds) ]

이다. r 이 정규분포이면 그 적분도 정규분포라서, 정규분포 X 에 대해 E[e^(−X)] = e^(−평균 + 분산/2) 를 쓰면 닫힌 식이 나온다. τ = T − t 로 두면

P(t, T) = A(τ)·exp(−B(τ)·r(t))
B(τ) = (1 − e^(−aτ)) / a
ln A(τ) = (b − σ²/(2a²))·(B(τ) − τ) − σ²·B(τ)² / (4a)

로그 가격이 r 에 대한 1차 함수라서 이런 모형을 아핀(affine) 모형이라 부른다. 만기 τ 의 연속복리 금리는 y(τ) = −ln P / τ 이고, r 에 대한 기울기는 B(τ)/τ 다. 이 값이 만기가 길수록 작아진다는 게 뒤에서 중요하다.

#8의 FDM 관점에서 보면 이 가격은 PDE ∂P/∂t + a(b − r)·∂P/∂r + (1/2)σ²·∂²P/∂r² − r·P = 0 의 해이기도 하다. 바시첵은 운 좋게 닫힌 해가 있지만, 닫힌 해가 없는 금리 모형은 이 PDE를 금리 축 격자에서 FDM으로 푼다.

예시 숫자: 기준금리 3.00%, 국고채 3년 3.715%·10년 4.008%

오늘 시장 숫자를 넣는다. 2026년 10월 30일 서울 채권시장에서 국고채 3년물은 연 3.715%(전 거래일보다 5.1bp 하락), 10년물은 연 4.008%로 마감했다. 단기금리 출발점 r(0) 은 10월 22일 동결된 기준금리 연 3.00%로 둔다. 기준금리가 3.00% 인데 3년 금리가 3.7% 대라는 것은, 시장이 앞으로 단기금리가 더 올라 있을 것이라 본다는 뜻으로 읽을 수 있다.

국고채 금리는 반기 이표 기준 금리라서 2·ln(1 + y/2) 로 연속복리로 바꾸고, 이를 같은 만기 할인채 금리로 간주한다(엄밀히는 이표채 금리와 할인채 금리가 다르다. 그 차이를 푸는 일은 키워드 로드맵의 부트스트래핑에서 다룬다). σ = 연 1%p 는 가정이다. 그러면 미지수 a, b 두 개를 3년·10년 두 점에 정확히 맞출 수 있다. 이런 작업을 캘리브레이션이라고 한다.

파이썬과 QuantLib으로 확인

import numpy as np
import QuantLib as ql
from scipy.optimize import fsolve

# 2026-10-22 기준금리 3.00% / 2026-10-30 국고채 3년 3.715%, 10년 4.008%
r0 = 0.03
y3_mkt, y10_mkt = 0.03715, 0.04008
cc = lambda y: 2*np.log(1 + y/2)          # 반기복리 -> 연속복리
z3, z10 = cc(y3_mkt), cc(y10_mkt)
print(f"연속복리 환산: 3년 {z3:.4%}, 10년 {z10:.4%}")

def vasicek_P(tau, r, a, b, s):
    B = (1 - np.exp(-a*tau))/a
    lnA = (b - s**2/(2*a**2))*(B - tau) - s**2*B**2/(4*a)
    return np.exp(lnA - B*r)
def vasicek_y(tau, r, a, b, s):
    return -np.log(vasicek_P(tau, r, a, b, s))/tau

sigma = 0.01                               # 가정: 단기금리 변동성 연 1%p
def eqs(x):
    a, b = x
    return [vasicek_y(3, r0, a, b, sigma) - z3, vasicek_y(10, r0, a, b, sigma) - z10]
a, b = fsolve(eqs, [0.3, 0.045])
print(f"\n[1] 3년·10년에 맞춘 바시첵 파라미터 (sigma=1% 가정)")
print(f"a(회귀 속도) = {a:.4f}, b(장기 평균) = {b:.4%}, 반감기 = {np.log(2)/a:.2f}년")
print("만기별 모형 금리(연속복리):")
for t in [0.25, 1, 2, 3, 5, 10, 20, 30]:
    print(f"  {t:>5}년: {vasicek_y(t, r0, a, b, sigma):.4%}")
print(f"장기 극한 금리 b - s^2/(2a^2) = {b - sigma**2/(2*a**2):.4%}")

# 2. 몬테카를로: 정확 이산화로 r 경로 생성 후 3년 할인채 가격 비교
rng = np.random.default_rng(2026)
n, steps, T = 100_000, 360, 3.0
dt = T/steps
e = np.exp(-a*dt); sd = sigma*np.sqrt((1 - e**2)/(2*a))
r = np.full(n, r0); integ = np.zeros(n)
for _ in range(steps):
    r_new = b + (r - b)*e + sd*rng.standard_normal(n)
    integ += 0.5*(r + r_new)*dt
    r = r_new
P_mc = np.exp(-integ).mean()
P_cf = vasicek_P(T, r0, a, b, sigma)
print(f"\n[2] 3년 할인채 가격: 해석해 {P_cf:.6f}, 몬테카를로 {P_mc:.6f} (표준오차 {np.exp(-integ).std()/np.sqrt(n):.6f})")
m = b + (r0 - b)*np.exp(-a*T); v = sigma**2/(2*a)*(1 - np.exp(-2*a*T))
print(f"3년 뒤 단기금리: 이론 평균 {m:.4%}, 표준편차 {np.sqrt(v):.4%} / 시뮬레이션 평균 {r.mean():.4%}, 표준편차 {r.std():.4%}")
from math import erf, sqrt
print(f"3년 뒤 단기금리 < 0 확률: 시뮬레이션 {(r<0).mean():.4%}, 이론 {0.5*(1+erf(-m/np.sqrt(v)/sqrt(2))):.2e}")

# 3. QuantLib 바시첵 모형으로 같은 가격
vm = ql.Vasicek(r0, a, b, sigma)
print(f"\n[3] QuantLib Vasicek discountBond(0,3) = {vm.discountBond(0.0, 3.0, r0):.6f}, (0,10) = {vm.discountBond(0.0, 10.0, r0):.6f}")
print(f"해석해 10년 = {vasicek_P(10, r0, a, b, sigma):.6f}")

# 4. 단기금리 0.25%p 인상 충격 시 만기별 금리 변화 (평행이동이 아님)
print("\n[4] r0 +25bp 충격 시 만기별 금리 변화")
for t in [1, 3, 10, 30]:
    d = (vasicek_y(t, r0+0.0025, a, b, sigma) - vasicek_y(t, r0, a, b, sigma))*1e4
    print(f"  {t:>2}년: {d:+.1f}bp  (B(t)/t = {(1-np.exp(-a*t))/(a*t):.3f})")

# 5. CIR: 같은 a, b 에서 변동성이 금리 수준에 비례
sig_cir = sigma/np.sqrt(r0)
print(f"\n[5] CIR (sigma_CIR = {sig_cir:.4f}, 2ab - sigma^2 = {2*a*b - sig_cir**2:.5f} > 0 이면 0에 닿지 않음)")
cir = ql.CoxIngersollRoss(r0, b, a, sig_cir)   # 순서: r0, 장기평균, 회귀속도, 변동성
for t in [3, 10]:
    P = cir.discountBond(0.0, float(t), r0)
    print(f"  CIR {t}년 금리 = {-np.log(P)/t:.4%}  vs 바시첵 {vasicek_y(t, r0, a, b, sigma):.4%}")

출력에서 읽은 것

  • 두 점에 맞추니 곡선 전체가 나온다. 3년·10년에 맞춘 결과 a = 0.7732, b = 4.12%. 모형은 1년 3.34%, 5년 3.83%, 30년 4.06% 처럼 나머지 만기도 다 만들어 낸다. 초단기 3.0% 에서 출발해 4.1% 근처로 완만하게 올라가는 모양이다. 다만 이건 모형이 그린 곡선이고, 실제 1년·5년·30년 금리와 맞는지는 별개다. 두 개 파라미터로 곡선 모양을 다 맞추기는 어렵다. 이게 바시첵의 두 번째 약점이고, 로드맵의 헐-화이트 모형이 이 문제를 푼다.
  • 반감기 0.9년. a = 0.7732 이면 단기금리가 장기 평균에서 벗어난 정도가 약 0.9년마다 절반으로 준다. 회귀가 꽤 빠른 편이라 3년 뒤 단기금리의 평균은 이미 4.01% 로 b 에 가깝다.
  • 닫힌 해, 몬테카를로, QuantLib 세 값이 맞는다. 3년 할인채 가격이 해석해 0.895451, 10만 경로 몬테카를로 0.895451(표준오차 0.000042), QuantLib Vasicek 0.895451. 몬테카를로는 #7처럼 경로를 만들되, 오늘은 주가 대신 r 경로를 만들고 그 적분을 할인에 썼다. 정확 이산화(위의 평균·분산 식으로 한 칸씩 이동)를 써서 시간 간격에 따른 오차가 없다.
  • 음의 금리 확률은 이 파라미터에선 작다. 3년 뒤 단기금리는 평균 4.01%, 표준편차 0.80% 의 정규분포다. 0 아래로 갈 확률은 이론상 2.71×10⁻⁷ 이고, 10만 경로 중에는 하나도 없었다. σ 가 크거나 금리 수준이 낮을 때는 이 확률이 무시할 수 없게 커진다.
  • 단기금리 충격은 곡선을 평행 이동시키지 않는다. r(0) 을 25bp 올리면 1년 금리는 +17.4bp, 3년 +9.7bp, 10년 +3.2bp, 30년 +1.1bp 만 움직인다. 정확히 25bp × B(τ)/τ 다. 평균 회귀 때문에 오늘의 충격은 시간이 지나면 사라질 것으로 보니, 먼 만기 금리에는 거의 반영되지 않는다. #3의 듀레이션은 모든 만기 금리가 똑같이 움직인다고 가정했는데, 금리 모형 안에서는 만기별 움직임이 모형 구조로 정해진다.
  • CIR은 같은 곡선을 거의 같게 만든다. 같은 a, b 에 σ 를 오늘 금리 수준에서 비슷해지도록 맞추니 3년 3.6803%, 10년 3.9663% 로 바시첵과 1bp 안쪽 차이다. 오늘의 곡선만 보면 두 모형의 차이는 작고, 차이는 금리가 낮아지는 시나리오에서 드러난다.

CIR 모형: 금리가 0 아래로 가지 않게

콕스-잉거솔-로스(CIR, 1985) 모형은 확산 항에 √r 를 곱한다.

dr(t) = a·(b − r(t))·dt + σ·√r(t)·dW(t)

금리가 0에 가까워지면 변동성도 0으로 줄어서 드리프트 a·b > 0 가 금리를 다시 밀어 올린다. 펠러 조건 2ab ≥ σ² 이 성립하면 금리가 0에 닿지도 않는다. 위 출력에서 2ab − σ² = 0.06038 > 0 이라 조건을 만족한다. 대신 r(t) 의 분포는 정규분포가 아니라 비중심 카이제곱 분포가 되어 계산이 더 복잡하다. 할인채 가격은 여전히 아핀 형태 A(τ)·e^(−B(τ)·r) 로 닫힌 식이 있다(A, B 식이 바시첵과 다르다).

정리하면 세 가지 축으로 비교된다.

음의 금리를 막는 게 항상 장점은 아니다. 유럽과 일본처럼 실제로 마이너스 금리를 겪은 시장에서는 오히려 바시첵 계열이 현실적이었다. 모형 선택은 시장과 상품에 따라 달라진다.

리스크관리에서 금리 모형이 필요한 곳

  • 금리옵션 평가: 채권옵션, 캡·플로어, 스왑션처럼 금리 경로에 따라 손익이 달라지는 상품은 금리 분포가 있어야 가격이 나온다.
  • 조기상환 조건이 있는 채권: 발행사가 금리가 내리면 일찍 갚을 수 있는 콜러블 채권은 #8처럼 격자 위에서 매 시점 조기상환 여부를 비교한다. 이때 격자의 축이 주가가 아니라 단기금리다.
  • 금리 시나리오와 민감도: 단기금리 충격이 만기별로 어떻게 전파되는지 모형으로 볼 수 있다. 다만 실무 민감도는 보통 시장 곡선의 각 만기 구간을 하나씩 움직이는 방식(키 레이트)으로 측정하고, 모형은 그 곡선을 정확히 재현하도록 맞춘 뒤 쓴다.

오늘 본 바시첵·CIR은 파라미터가 상수라 시장 곡선을 정확히 재현하지 못한다. 실제 평가에서는 b 를 시간의 함수로 바꿔 오늘의 할인곡선과 정확히 맞추는 헐-화이트 모형을 많이 쓴다. 시장 곡선 자체를 만드는 부트스트래핑과 함께 로드맵 뒤쪽에서 다룬다.

자주 묻는 질문

Q. 단기금리 r(0) 를 왜 기준금리로 두었나?

단기금리 모형의 r 은 이론상 아주 짧은 기간의 무위험 금리다. 기준금리는 콜금리 같은 초단기 시장금리의 목표 수준이라 출발점으로 쓰기 쉬운 숫자다. 실무에서는 초단기 시장 금리나 할인곡선의 가장 짧은 구간에서 읽는다. 오늘 예시에서는 단순화를 위한 가정이다.

Q. 캘리브레이션한 b = 4.12% 는 시장이 예상하는 장기 금리인가?

그대로 그렇게 읽으면 안 된다. 위험중립 측도에서의 파라미터라 기간 프리미엄이 섞여 있고, σ 를 1% 로 가정한 결과이기도 하다. σ 를 바꾸면 a, b 도 바뀐다. 모형 파라미터는 "이 곡선을 재현하는 값"이지 예측치가 아니다.

Q. 주가 모형에서 쓰던 블랙숄즈를 금리에 쓰면 안 되나?

채권옵션 하나만 볼 때는 블랙 공식 같은 시장 관행 공식을 쓰기도 한다. 하지만 여러 만기의 채권과 금리가 서로 일관되게 움직여야 하는 상품, 예를 들어 조기상환 채권이나 여러 시점의 금리가 얽힌 상품은 곡선 전체를 하나의 과정으로 묶는 금리 모형이 필요하다.

오늘의 한 줄

바시첵은 dr = a(b − r)dt + σdW 로 금리의 평균 회귀를 표현하고, 할인채 가격을 A(τ)·e^(−B(τ)r) 의 닫힌 식으로 준다. 3년·10년 국고채에 맞추니 a = 0.77, b = 4.12% 였고, 단기금리 25bp 충격은 10년 금리에 3.2bp 만 전해졌다. CIR은 √r 로 음의 금리를 막는다. 다음 일기 #10은 신용위험과 부도 확률.
