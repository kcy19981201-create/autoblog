2026년 10월 26일.

#3까지는 현금흐름이 정해진 상품만 다뤘다. 오늘부터는 손익이 꺾이는 상품, 옵션이다. 결론부터 적으면, 옵션 가격은 주식과 채권으로 옵션의 손익을 똑같이 복제하는 데 드는 돈이다. 이 복제 비용을 계산해 보면 주가가 오를 "진짜" 확률은 식에서 사라지고, 대신 위험중립 확률 q라는 계산용 확률이 남는다. 이항 트리는 이 아이디어를 가장 단순한 세계에서 보여주는 도구이고, 단계를 잘게 쪼개면 블랙숄즈 값으로 수렴한다.

직관: 위 아니면 아래, 두 갈래만 있는 세계

주가가 다음 시점에 딱 두 값 중 하나만 된다고 가정하자. 올라서 S·u 가 되거나, 내려서 S·d 가 된다. 이 세계에서 콜옵션의 만기 손익도 두 값뿐이다. 그러면 주식 Δ주와 현금 B원을 적당히 섞어서, 위로 가든 아래로 가든 콜옵션과 정확히 같은 돈이 되게 만들 수 있다. 미지수 두 개(Δ, B)에 방정식 두 개(위, 아래)라서 답이 하나로 정해진다.

손익이 똑같은 두 묶음은 오늘 가격도 같아야 한다. 다르면 싼 쪽을 사고 비싼 쪽을 팔아 위험 없이 차익을 얻는다. #2에서 선도가격을 정할 때 쓴 무차익 논리를 그대로 가져온 것이다. 차이는 선도는 주식 1주와 차입만으로 복제됐고, 옵션은 주식 수 Δ 를 상황에 맞춰 골라야 한다는 점이다. 이 Δ 가 나중에 그릭스에서 다시 나올 델타다.

예시 숫자: 2026년 10월 23일 코스피로 1단계 트리

2026년 10월 23일 코스피는 5,550.30에 마감했고, 한국은행은 하루 전인 10월 22일 기준금리를 연 3.00%로 동결했다. 이 둘을 빌려 와서, 코스피 지수를 기초자산으로 하는 가상의 유럽형 콜옵션을 평가해 본다. 행사가 5,550, 만기 91일(2027년 1월 22일), 무위험이자율 연 3.00%(연속복리로 간주), 변동성 연 30%, 배당 없음은 모두 가정이다. 실제 지수옵션은 코스피200을 기초자산으로 하니, 여기서는 순전히 숫자 감각을 위한 예시다.

변동성 30%를 트리로 옮기는 방법은 아래 수식에서 다루고, 결과만 먼저 쓰면 u = 1.161595, d = 0.860885 이다.

  • 위로 가면 지수 6,447.20 → 콜 손익 897.20
  • 아래로 가면 지수 4,778.17 → 콜 손익 0
  • 델타 Δ = (897.20 − 0) / (6,447.20 − 4,778.17) = 0.5376
  • 현금 B = −2,549.41 (빌린다는 뜻)
  • 복제 비용 = 0.53756 × 5,550.30 − 2,549.41 = 434.20

콜을 복제하려면 지수를 0.5376 단위 사고, 그 돈의 일부를 빌려서 마련하면 된다. 이 묶음의 오늘 값 434.20 이 1단계 트리가 매긴 콜 가격이다. 계산 어디에도 "코스피가 오를 확률"이 들어가지 않았다는 게 오늘의 핵심이다.

수식: 위험중립 확률과 CRR 트리

복제 조건을 풀면 가격을 다음처럼 다시 쓸 수 있다. Δt 는 한 단계의 길이(년), r 은 연속복리 무위험이자율이다.

Δ = (C_u − C_d) / (S·u − S·d)
C = e^(−rΔt) · [ q·C_u + (1 − q)·C_d ]
q = (e^(rΔt) − d) / (u − d)        ← 위험중립 확률

CRR(Cox-Ross-Rubinstein):  u = e^(σ√Δt),  d = 1/u

두 번째 줄은 "q 를 확률로 보고 만기 손익의 기댓값을 무위험이자율로 할인한 것"과 모양이 같다. 그래서 q 를 위험중립 확률이라 부른다. 진짜 확률이 아니라, 모든 자산의 기대수익률이 무위험이자율이 되도록 맞춘 가상의 확률이다. 위 예시에서 q = 0.4876 이고, 이걸로 할인한 기댓값도 434.20 으로 복제 비용과 같다. q 가 0과 1 사이에 있으려면 d < e^(rΔt) < u 여야 하는데, 이게 바로 무차익 조건이다. 주식이 무위험 채권보다 항상 더 벌거나 항상 덜 벌면 차익거래가 생긴다.

u, d 는 아무렇게나 정하지 않는다. 한 단계에서 로그수익률 ln(S_다음/S) 은 +σ√Δt 또는 −σ√Δt 이고, 대략 반반으로 나오니 분산이 σ²Δt 가 된다. 실제 주가 모형(로그수익률의 분산이 시간에 비례해 σ²t)과 분산을 맞춘 것이다. N 단계 뒤 상승 횟수 j 는 이항분포를 따르고, 만기 주가는 S·u^j·d^(N−j) 다. 확률론의 중심극한정리(독립인 작은 변화를 많이 더하면 정규분포에 가까워진다)에 따라 N 이 커지면 로그주가가 정규분포, 즉 주가가 로그정규분포로 수렴한다. 블랙숄즈가 가정하는 바로 그 분포다.

N 단계 트리는 만기 손익에서 시작해 한 단계씩 거꾸로 올라오며 위 두 번째 줄을 반복한다(역방향 귀납, backward induction). 미국형 옵션은 각 마디에서 "계속 들고 있을 때 가치"와 "지금 행사할 때 가치" 중 큰 값을 고르기만 하면 된다. 매 시점 최선의 선택을 뒤에서부터 정하는 이 방식은 수치해석에서 말하는 동적계획법이다. 해석적 공식이 없는 미국형 옵션을 트리가 쉽게 푸는 이유가 여기 있다.

파이썬과 QuantLib으로 확인

import numpy as np
import QuantLib as ql

# 2026-10-23 코스피 종가 5,550.30 / 기준금리 3.00% (2026-10-22 동결)
S0, K, r, sigma, T = 5550.30, 5550.0, 0.03, 0.30, 91/365   # 변동성 30%, 만기 91일은 가정

# 1) 1단계 트리: 복제 포트폴리오
dt = T
u = np.exp(sigma*np.sqrt(dt)); d = 1/u
Su, Sd = S0*u, S0*d
Cu, Cd = max(Su-K, 0), max(Sd-K, 0)
delta = (Cu-Cd)/(Su-Sd)
B = (Cu - delta*Su)*np.exp(-r*dt)
q = (np.exp(r*dt)-d)/(u-d)
print(f"u={u:.6f} d={d:.6f} Su={Su:,.2f} Sd={Sd:,.2f} Cu={Cu:,.2f} Cd={Cd:,.2f}")
print(f"델타={delta:.4f}  채권(현금)={B:,.2f}  복제가격={delta*S0+B:,.2f}")
print(f"위험중립 q={q:.4f}  q로 할인한 기댓값={np.exp(-r*dt)*(q*Cu+(1-q)*Cd):,.2f}")

# 2) CRR N단계
def crr(S0, K, r, sigma, T, N, kind="call", american=False):
    dt = T/N
    u = np.exp(sigma*np.sqrt(dt)); d = 1/u
    q = (np.exp(r*dt)-d)/(u-d); disc = np.exp(-r*dt)
    j = np.arange(N+1)
    S = S0 * u**(N-j) * d**j
    V = np.maximum(S-K, 0) if kind == "call" else np.maximum(K-S, 0)
    for n in range(N-1, -1, -1):
        S = S0 * u**(n-np.arange(n+1)) * d**np.arange(n+1)
        V = disc*(q*V[:-1] + (1-q)*V[1:])
        if american:
            ex = np.maximum(S-K, 0) if kind == "call" else np.maximum(K-S, 0)
            V = np.maximum(V, ex)
    return V[0]

# 블랙숄즈 기준값 (QuantLib)
today = ql.Date(23, 10, 2026); ql.Settings.instance().evaluationDate = today
dc = ql.Actual365Fixed()
spot = ql.QuoteHandle(ql.SimpleQuote(S0))
rts = ql.YieldTermStructureHandle(ql.FlatForward(today, r, dc, ql.Continuous))
qts = ql.YieldTermStructureHandle(ql.FlatForward(today, 0.0, dc, ql.Continuous))
vts = ql.BlackVolTermStructureHandle(ql.BlackConstantVol(today, ql.NullCalendar(), sigma, dc))
proc = ql.BlackScholesMertonProcess(spot, qts, rts, vts)
mat = today + 91
Tq = dc.yearFraction(today, mat)

euc = ql.VanillaOption(ql.PlainVanillaPayoff(ql.Option.Call, K), ql.EuropeanExercise(mat))
euc.setPricingEngine(ql.AnalyticEuropeanEngine(proc))
bs_call = euc.NPV()
eup = ql.VanillaOption(ql.PlainVanillaPayoff(ql.Option.Put, K), ql.EuropeanExercise(mat))
eup.setPricingEngine(ql.AnalyticEuropeanEngine(proc))
bs_put = eup.NPV()
print(f"블랙숄즈 콜={bs_call:,.2f} 풋={bs_put:,.2f}")

print("N, 유럽콜, 오차, 유럽풋, 미국풋, 조기행사 프리미엄")
for N in [1, 2, 3, 10, 11, 50, 51, 100, 500, 1000]:
    c = crr(S0, K, r, sigma, Tq, N, "call")
    p = crr(S0, K, r, sigma, Tq, N, "put")
    pa = crr(S0, K, r, sigma, Tq, N, "put", american=True)
    print(f"{N:5d} {c:10,.2f} {c-bs_call:+8.2f} {p:10,.2f} {pa:10,.2f} {pa-p:7.2f}")

# 3) QuantLib 이항 엔진
amp = ql.VanillaOption(ql.PlainVanillaPayoff(ql.Option.Put, K), ql.AmericanExercise(today, mat))
for N in [100, 1000]:
    euc.setPricingEngine(ql.BinomialVanillaEngine(proc, "crr", N))
    amp.setPricingEngine(ql.BinomialVanillaEngine(proc, "crr", N))
    print(f"QuantLib CRR N={N}: 유럽콜={euc.NPV():,.2f}  미국풋={amp.NPV():,.2f}  델타(콜)={euc.delta():.4f}")

# 변동성 민감도: 30% vs 55%
for s in [0.30, 0.55]:
    print(f"sigma={s:.0%}: 유럽콜 N=1000 = {crr(S0, K, r, s, Tq, 1000, 'call'):,.2f}")

# 4) 배당 없는 미국형 콜 = 유럽형 콜?
print(f"미국콜 N=1000 = {crr(S0, K, r, sigma, Tq, 1000, 'call', american=True):,.2f}")

출력에서 읽은 것

  • 복제 비용과 위험중립 기댓값이 434.20 으로 같다. 같은 계산을 두 가지 언어로 쓴 것뿐이다. 복제는 "왜 이 가격이어야 하나"를, q 는 "어떻게 빨리 계산하나"를 맡는다.
  • 1단계 트리는 크게 틀린다. 블랙숄즈 기준 351.37 에 비해 N=1 은 +82.83 이나 높다. 두 갈래뿐인 세계는 너무 거칠다. N=100 이면 오차 −0.81, N=1000 이면 −0.08 로 줄어든다. 단계를 열 배 늘리면 오차가 대략 열 분의 일이 되니 오차가 1/N 에 비례해 줄어드는 모습이다.
  • 오차가 홀짝으로 부호를 바꾼다. N=10 은 −8.11, N=11 은 +7.52, N=50 은 −1.63, N=51 은 +1.61 이다. 행사가가 트리 마디 사이 어디에 걸리느냐에 따라 위아래로 튀는 것이다. 실무에서 이항 트리를 쓸 때 N 을 하나만 정해 두면 이 흔들림을 놓친다. 연속한 두 N 의 평균을 쓰거나 마디를 행사가에 맞추는 변형 트리를 쓰는 이유다.
  • 미국형 풋은 유럽형보다 비싸다. N=1000 에서 유럽 풋 309.64, 미국 풋 312.66 으로 조기행사 권리 값이 3.03 이다. 반면 배당 없는 미국형 콜은 351.29 로 유럽형과 똑같다. 배당이 없으면 콜은 일찍 행사해서 얻는 게 없다는 고전적인 결과를 숫자로 확인했다.
  • QuantLib 의 CRR 엔진과 직접 짠 코드가 소수 둘째 자리까지 일치한다. 엔진이 돌려주는 델타 0.5498 은 1단계 트리의 0.5376 보다 조금 크다. 트리가 촘촘해질수록 델타도 연속시간 값으로 다가간다.

한계: 트리가 가정하는 것

가장 큰 가정은 변동성 σ 가 상수라는 점이다. 트리 전체에서 u, d 가 똑같다. 그런데 σ 를 30%에서 55%로 바꾸면 같은 콜 가격이 351.29 에서 624.81 로 거의 두 배가 된다. 55%를 골라 본 이유가 있다. 코스피200 옵션 가격에서 역산한 변동성지수 VKOSPI 는 10월 14일 44.91, 15일에는 55선에서 마감했다. 시장이 출렁일 때는 이 숫자 하나가 가격을 좌우한다. 옵션 시장 가격에서 거꾸로 σ 를 뽑아내는 내재변동성은 블랙숄즈를 다룰 때 다시 본다.

두 번째는 무위험이자율과 배당을 상수로 둔 것이다. #1 에서 만든 할인곡선을 쓰려면 단계마다 다른 금리를 넣어야 하고, 배당이 있으면 q 식의 r 자리에 (r − 배당수익률)이 들어간다. 세 번째는 계산량이다. 기초자산이 하나면 마디 수가 N²/2 정도라 가볍지만, 기초자산이 둘만 돼도 트리가 격자로 커진다. 기초자산이 많은 상품은 몬테카를로로, 경계 조건이 까다로운 상품은 유한차분법으로 넘어가게 되는데, 둘 다 로드맵에 있다.

자주 묻는 질문

Q. 위험중립 확률이 진짜 확률이 아니면, 오를 확률은 가격과 상관없나?

복제가 가능하다는 가정 아래에서는 그렇다. 진짜 확률에 대한 시장의 생각은 이미 오늘 주가 S 에 반영돼 있고, 옵션 가격은 S 와 무위험이자율, 변동성으로부터 무차익 조건만으로 정해진다. 그래서 낙관론자와 비관론자가 같은 옵션 가격에 동의할 수 있다.

Q. N 은 얼마나 크게 잡아야 하나?

위 예시에서 N=100 은 오차 1원 안쪽, N=500 은 0.2원 안쪽이었다. 원하는 정확도와 계산 시간의 타협이다. 다만 홀짝 진동 때문에 N 을 키우는 것만으로는 매끄럽게 수렴하지 않는다는 점, 민감도를 차분으로 구할 때 이 진동이 더 크게 드러난다는 점은 기억해 둘 만하다.

Q. 그냥 블랙숄즈 공식을 쓰면 되지 않나?

유럽형 바닐라 옵션이라면 공식이 더 빠르고 정확하다. 트리는 미국형처럼 조기행사가 있는 상품, 그리고 위험중립 가격결정이 왜 성립하는지 손으로 확인할 때 쓸모가 있다. 오늘 결과에서 보듯 트리를 무한히 쪼갠 극한이 블랙숄즈이기도 하다.
